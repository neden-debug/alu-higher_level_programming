# Python - Hello, World

This project introduces Python basics: running Python scripts, printing output, and working with strings.

## Files

| File | Description |
|------|-------------|
| 0-run | Shell script that runs the Python file stored in the `$PYFILE` environment variable |
| 1-run_inline | Shell script that runs the Python code stored in the `$PYCODE` environment variable |
| 2-print.py | Prints "Programming is like building a multilingual puzzle |
| 4-print_float.py | Prints a float with 2 decimal places using an f-string |
| 5-print_string.py | Prints a string 3 times, then its first 9 characters |
| 6-concat.py | Concatenates two strings to print Welcome to Holberton School! |
| 7-edges.py | Uses slicing to get the first 3, last 2 and middle letters of a word |
| 8-concat_edges.py | Builds a new sentence using only slices of an existing string |
| 9-easter_egg.py | Prints The Zen of Python |
